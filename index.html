Claim by claim

  1. Split into claims

    A language model reads the text and breaks it into short statements that can each be true or false on their own. Opinions, questions and filler are left out, and numbers, dates and names are kept exactly as written.

  2. Check each one

    Every claim is checked against well-established facts. The checker is told to answer “unverifiable” rather than guess, and to give the correct figure whenever something is wrong.

  3. Score and cite

    Each claim gets a confidence from 0 to 100 and a link to read further. The trust score is simply the share of claims that came back verified. Anything under your confidence threshold in Settings is dimmed.

What the marks mean

Verified

Backed by a trusted source with high confidence. The source is linked so you can see it for yourself.

Unverifiable

Nothing solid either way. That doesn’t make it false, it just means you shouldn’t lean on it without checking.

Wrong

Contradicted by reliable sources. The explanation gives the correct fact and where it comes from.

Treat this as a second opinion, not a ruling. Open the source before you rely on anything that matters.

About this project

Language models write with the same confidence whether they are right or making things up. Hallucination Hunter reads an answer one claim at a time so you can see exactly which sentences to trust.

How a check works

  1. Extraction. The answer is split into single factual claims.
  2. Verification. Each claim is checked and given a confidence score.
  3. Attribution. Every verdict comes with a source to read.
  4. Mark-up. The original text is annotated so problems are easy to spot.

Under the hood

  • Front end: plain HTML, CSS and JavaScript. No framework, no build step.
  • Model: openai/gpt-oss-120b on Groq. On Vercel the API key stays server-side in api/groq.js.
  • Storage: Supabase (Postgres) for checks, claims and settings.
  • Also on: a Chrome extension and an Android app built from this same code.

Privacy

Text you check is sent to the model provider to be analysed and stored with your checks under a random ID that lives in this browser. There is no account and no tracking. Share links keep the result in the link itself, so nothing extra is uploaded when you share.
