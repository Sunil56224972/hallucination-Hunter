❓ The Problem

Why do we need Hallucination Hunter?

🤖

AI Makes Stuff Up

ChatGPT, Gemini, Claude — all LLMs sometimes generate facts that sound real but are completely wrong. These are called "hallucinations."

😰

Hard to Spot

AI-generated text sounds so confident and well-written that even experts can't always tell which facts are real and which are fake.

📝

Students & Professionals at Risk

People copy-paste AI text into assignments, reports, and articles without checking — spreading misinformation unknowingly.

⏰

Manual Checking is Slow

Fact-checking every single claim by hand takes hours. You'd need to Google each statement individually. Nobody has that kind of time.

🏷️ Claim Classification System

Every claim gets one of three ratings with a confidence score

✅

VERIFIED

The claim is supported by trusted sources. It's accurate and you can trust it.

Example: "The Earth orbits the Sun" → ✅ Verified (98%)

⚠️

UNVERIFIABLE

No matching source found. The claim might be true but can't be confirmed right now.

Example: "AI will replace 80% of jobs by 2030" → ⚠️ Unverifiable (45%)

❌

INCORRECT

The claim is contradicted by trusted sources. It's wrong and needs correction.

Example: "Python was created in 2005" → ❌ Incorrect (Created in 1991)

🛠️ Tech Stack

Technologies used to build Hallucination Hunter

🌐

Frontend — HTML5, CSS3, JavaScript

Pure vanilla web technologies. No heavy frameworks. Fast loading, responsive design with warm monochrome theme.

🤖

AI Engine — Groq API (LLaMA 3)

Ultra-fast AI inference via Groq. Uses LLaMA 3 model to extract claims and verify them. Sub-second response times.

📱

Mobile — Capacitor (Android APK)

Web app wrapped as native Android app using Capacitor. Same codebase, native mobile experience with bottom nav.

🚀

Hosting — Vercel (Serverless)

Deployed on Vercel with serverless API routes. Auto-scaling, zero downtime, global CDN for fast access.

🎤

Voice — Web Speech API

Browser-native speech recognition. No external service needed. Works in Chrome & Edge. Real-time transcription.

🗄️

Database — Supabase (Planned)

PostgreSQL cloud database for storing analysis history, user settings, and dashboard analytics. Coming in Round 2.
